Logs sin agente (Alloy + Loki)

Alloy monta /var/run/docker.sock → escucha stdout de todos los contenedores.

Añade etiqueta service="odoo-minion-1" automáticamente.

Loki solo indexa etiquetas (no texto completo) → muy ligero.

logql {service="odoo-minion-1"} |= "ERROR" en Grafana Explore.

En versión bajos recursos se elimina para ahorrar RAM → logs con docker logs.

Buenas prácticas (resumen)

  • Idempotencia: Terraform y estados Salt seguros de repetir.
  • Alert fatigue: usar for: 5m en Prometheus.
  • Mínimo privilegio: contenedores como user = "odoo" (no root).
  • Volúmenes externos: PostgreSQL, Prometheus, Grafana, Loki.
  • Backups: de volúmenes (docker run --rm -v ...).

Versión «Bajos recursos»

  • Un solo Odoo + PostgreSQL (elimina .58 y .60).
  • Sin Loki ni Alloy → logs solo con docker logs.
  • Memoria Odoo: 1024 MB (en lugar de 1536).
  • Opcional: eliminar cAdvisor o reducir memoria de Prometheus.
  • Consumo total ≈ 3–4 GB RAM.
