Repositorio del curso *DevOps y Monitorización*, diseñado para aprender automatización de sistemas, despliegues, monitorización e integración continua desde un enfoque práctico y progresivo.  
Cada unidad incluye contenidos teóricos, laboratorios guiados, ejemplos reproducibles y materiales complementarios orientados al entorno profesional y educativo de Formación Profesional en Informática.

Además, el repositorio incorpora **podcast de repaso de cada unidad**, disponibles en la carpeta `Podcast`, pensados para reforzar contenidos, facilitar la memorización y ofrecer un formato accesible para estudio en movilidad.

---

## 📚 Contenidos del curso

| # | Unidad | Estado |
|---|--------|--------|
| 01 | **Introducción al curso y entorno de trabajo** — Conceptos base de automatización, virtualización, herramientas y ecosistema DevOps | ✅ |
| 02 | **Introducción a la automatización con Vagrant** — Creación y provisión de entornos virtualizados, boxes, provisioners y automatización de laboratorios | ✅ |
| 03 | **Despliegue automatizado con FOG sobre PXE** — Imagen de sistemas, despliegue en red, servidor FOG, arranque PXE y clonación | ✅ |
| 04 | **Automatización remota con Salt y monitorización de sistemas** — Gestión de configuración remota, estados, pillars, grains y supervisión de infraestructura | ✅ |
| 05 | **Automatización y monitorización en Odoo** — Integración de automatización con sistemas ERP, despliegue de Odoo y monitorización asociada | ✅ |
| 06 | **Automatización y CI/CD: Despliegue y monitorización con Jenkins** — Pipelines, integración continua, despliegue automatizado y supervisión con Jenkins | ✅ |

---

## 🎯 Objetivos del curso

- Comprender y aplicar principios reales de **automatización de sistemas e Infraestructura como Código**
- Automatizar despliegues y configuración de sistemas con Vagrant, Salt y FOG
- Implementar pipelines de **Integración Continua y Despliegue Continuo (CI/CD)** con Jenkins
- Monitorizar infraestructuras y servicios de forma proactiva
- Desarrollar competencias alineadas con perfiles **DevOps y Cloud Engineer**
- Servir como recurso docente para ciclos de **FP Informática**
- Facilitar repaso auditivo mediante **podcast temáticos por unidad**

---

## 🧩 Requisitos recomendados

- Conocimientos básicos de sistemas y virtualización
- Entornos Linux o compatibles
- Git instalado
- Ganas de aprender experimentando 😄

## 🛠 Tecnologías y herramientas

| Tecnología | Propósito |
|------------|-----------|
| **Vagrant** | Automatización de entornos virtualizados |
| **FOG Project** | Despliegue masivo de imágenes por red (PXE) |
| **Salt Project** | Gestión de configuración remota y orquestación |
| **Odoo** | ERP con automatización y monitorización integrada |
| **Jenkins** | CI/CD, pipelines y despliegue automatizado |
| **VirtualBox** | Hipervisor para entornos de laboratorio |
