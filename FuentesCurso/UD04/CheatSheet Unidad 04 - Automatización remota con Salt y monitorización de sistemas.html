2. Inteligencia PromQL y Alertas

Prometheus no usa bases de datos relacionales (SQL). Evalúa Time-Series (series temporales basadas en etiquetas) mediante álgebra sobre Vectores Instantáneos (el milisegundo actual) y Vectores de Rango (histórico).

A. Regex & Endpoint Health up{job=~".*-node"} == 0

Lógica: La métrica up es generada internamente por Prometheus (1=Pull OK, 0=Timeout). Usamos la expresión regular =~".*-node" para vigilar dinámicamente cualquier contenedor o máquina que caiga, sin necesidad de harcodear IPs.

B. Álgebra Vectorial (RAM) (1 - (node_memory_MemAvailable_bytes / node_memory_MemTotal_bytes)) * 100 > 95

Lógica: Los agentes envían bytes crudos. PromQL evalúa algebraicamente dos series temporales distintas, realizando cálculos matemáticos al vuelo para disparar la alerta cuando el clúster cruza el 95% de uso real de RAM.

C. Regresión Predictiva predict_linear(node_filesystem_free_bytes{mountpoint="/"}[6h], 24*3600) < 0

Lógica: Convierte la consulta en un Vector de Rango [6h]. Analiza la velocidad exacta a la que se llena el disco duro en las últimas 6 horas y aplica matemáticas predictivas para alertar si nos quedaremos sin espacio en las próximas 24 horas.

D. Ventanas de Contadores increase(node_vmstat_oom_kill[5m]) > 0

Lógica: Los contadores (Counters) siempre crecen. Si el Kernel aniquila un proceso por falta de RAM, el contador sube. increase() evalúa solo los eventos nuevos detectados en la ventana móvil de los últimos 5 minutos.

# Definición declarativa del Contenedor Master
resource "docker_container" "vm_master" {
  name     = "vm-master"
  image    = "ubuntu:24.04"
  
  # IP Estática Inamovible (.40)
  networks_advanced {
    name         = docker_network.internal_net.name
    ipv4_address = "172.28.0.40"
  }

  # Volúmenes (Persistencia de BD Temporal)
  volumes {
    volume_name    = docker_volume.prometheus_data.name
    container_path = "/var/lib/prometheus"
  }

  # Inyección de configuración (Upload al vuelo)
  upload {
    source = "${path.cwd}/../monitoring/prometheus.yml"
    file   = "/etc/prometheus/prometheus.yml"
  }
}
